# BUG-001 — Incorrect Product Images

**Status:** Reproduced  
**Module:** Inventory  
**Environment:** SauceDemo  
**Affected user:** `problem_user`

## Description

Product images are incorrectly displayed when accessing the inventory page using the `problem_user` account. Multiple products display repeated images instead of their corresponding product images.

## Preconditions

- Access to https://www.saucedemo.com/
- Login with `problem_user` and the password `secret_sauce`.

## Steps to Reproduce

1. Navigate to SauceDemo.
2. Log in using `problem_user`.
3. Open the inventory page.
4. Inspect the images displayed for each product.

## Expected Result

Each product should display its corresponding image.

## Actual Result

All six products display the same image instead of their corresponding product images.

## Comparison

When using `standard_user`, all six products display their correct images.

## Severity

Medium — Proposed.

## Automated Test Evidence

Automated test: `test_problem_user_product_images`

The test verifies that six product images are displayed and that each image has a unique source URL.

**Actual result:** All six images return the same source:

`/assets/sl-404-Cq1a9k9X.jpg`

**Test result:** XFAIL — Expected failure due to BUG-001.
