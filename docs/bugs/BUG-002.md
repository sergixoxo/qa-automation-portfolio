# BUG-002 — Remove Button Not Working

**Status:** Reproduced  
**Module:** Inventory  
**Environment:** SauceDemo  
**Affected user:** `problem_user`

## Description

The Remove button does not respond when attempting to remove a product directly from the inventory page using the `problem_user` account.

## Preconditions

- Access to https://www.saucedemo.com/
- Login with `problem_user` and the password `secret_sauce`.

## Steps to Reproduce

1. Navigate to SauceDemo.
2. Log in using `problem_user`.
3. Locate Sauce Labs Backpack and click "Add to cart".
4. Click the "Remove" button displayed on the inventory page.
5. Observe the product and cart counter.

## Expected Result

The selected product should be removed from the cart, the cart counter should update, and the button should return to "Add to cart".

## Actual Result

Clicking "Remove" produces no visible change. The product remains in the cart.

## Comparison

When using `standard_user`, the Remove button works correctly.

## Severity

Medium — Proposed.

## Automated Test Evidence

Automated test: `test_problem_user_remove_button`

The test adds Sauce Labs Backpack to the cart, clicks the Remove button, and verifies that the button returns to "Add to cart".

**Actual result:** The Remove button does not remove the product from the cart.

**Test result:** XFAIL — Expected failure due to BUG-002.
